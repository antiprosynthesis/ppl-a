# 40 Communication / Radiotelephony — CHEAT SHEET

*Covers all 82 bank questions (Q-numbers in brackets). Sources: lessons (J. De Boeck), CAP 413 phraseology, ECQB bank. Where sources differ, the **bank answer** is shown and flagged ⚠.*

---

## 1. PHONETIC ALPHABET + DIGITS  (Q35, Q36)
**HOW TO USE:** spell call signs letter by letter. *Spelling traps:* **Yankee** (not Jankee), **Juliett** (double t), **Mike** (not Mikro), **Hotel** (not Home), **Oscar** (not Omega), **Kilo** (not Kilogramm).

| A Alfa | B Bravo | C Charlie | D Delta | E Echo | F Foxtrot |
|---|---|---|---|---|---|
| G Golf | H Hotel | I India | J Juliett | K Kilo | L Lima |
| M Mike | N November | O Oscar | P Papa | Q Quebec | R Romeo |
| S Sierra | T Tango | U Uniform | V Victor | W Whiskey | X X-ray |
| Y Yankee | Z Zulu | | | | |

Digits: 0 **zero** · 1 **wun** · 2 **too** · 3 **tree** · 4 **fower** · 5 **fife** · 6 **six** · 7 **seven** · 8 **ait** · 9 **niner**. Also **decimal**, **hundred**, **tousand** (spelled "tousand" in the bank).

Examples: HB-YKM = **Hotel Bravo Yankee Kilo Mike** · OE-JVK = **Oscar Echo Juliett Victor Kilo** · D-EAZF = Delta Echo Alfa Zulu Foxtrot.

## 2. NUMBERS, TIME, VISIBILITY  (Q14–Q21, Q26)
**HOW TO USE:** *digit by digit*, except **whole hundreds/thousands** (altitude, cloud base) → digit + HUNDRED / TOUSAND.

| Item | Rule | Example |
|---|---|---|
| Altitude / height | digits + hundred/tousand | 4500 ft = **"four tousand five hundred"** (Q14) |
| Heading / bearing / wind dir | 3 digits, each separate, NO "hundred" | 285° = **"two eight five"** (Q15) |
| Flight level | digit by digit | FL075 = flight level zero seven five |
| Frequency | digit by digit + **decimal**; **drop trailing zeros** | 119.500 = **"one one niner decimal five"** (Q16) · 121.275 = one two one decimal two seven five |
| Time | **UTC** always (Q20); 4 digits one by one | 1620 = **"one six two zero"** (Q21), NOT "sixteen twenty" |
| Clock position (traffic) | normal number + "o'clock" | **"twelve o'clock"** (Q26), NOT "one two" |
| Visibility **≤ 5 km** | **metres** (Q17) | 800 m = eight hundred metres |
| Visibility **> 5 km** | **kilometres** (Q19) | 8 km = eight kilometres |
| Visibility **10 km or more** | "**one-zero kilometres or more**" (Q18) | 12 km → "one-zero kilometres or more" |

Mnemonic: *5 is the pivot: up to 5 = metres, above 5 = km; 10+ is capped at "one-zero or more".* Don't pick "up to 10 km"/"greater than 10 km".

## 3. STANDARD WORDS & PHRASES  (Q22–Q29, Q39)
| Say | Meaning | Use |
|---|---|---|
| **ROGER** | I have **received all** of your last transmission (Q22) | Acknowledge info that needs no action, e.g. "You are now entering airspace Delta" → **Roger** (Q45). **NOT yes, NOT permission, NOT "will comply"** |
| **WILCO** | I **understand** and will **comply** | Instruction with nothing to read back: "Next report PAH" → **Wilco** (Q75) |
| **AFFIRM** | Yes (Q29) | never "yes"/"affirmative"/"roger" |
| **NEGATIVE** | No (Q28) | never "no"/"not" |
| **APPROVED** | **Permission for proposed action is granted** (Q23) | |
| **CORRECTION** | An error was made; correct version is… | |
| **REQUEST** | the word to ask permission, e.g. to fly through controlled airspace (Q24) | not want / would like / apply |
| **READY FOR DEPARTURE** | ready for take-off (Q25) | "Ready for start-up" = engine start; "Ready"/"Request take-off" wrong |
| **GOING AROUND** | pilot announces go-around (Q27) | not pulling up / no landing / approach cancelled |
| **HOW DO YOU READ?** | check readability (Q39) | reply "Readability X" |

## 4. READABILITY SCALE  (Q40–Q43)
**1 Unreadable · 2 Readable now and then · 3 Readable but with difficulty · 4 Readable · 5 Perfectly readable.**
Mnemonic: 1-2-3 bad (un- → now&then → difficulty), 4 fine, 5 perfect.

## 5. CALL SIGNS & ESTABLISHING CONTACT  (Q34, Q37, Q38, Q70–Q73)
| Facility | Call-sign word |
|---|---|
| Aerodrome control | **Tower** (Q70) |
| Surface movement control | **Ground** (Q71) |
| Flight information service | **Information** (Q34), NOT "Info" |

* **First contact → FULL call sign (all characters)** (Q37).
* **Abbreviate only after the ground station has used the abbreviation** (Q38). Abbreviation = first character + last **two** letters: **D-EAZF → DZF** (Q72); HB-YKM → HKM.
* **Contact format:** *called station + own call sign* → **"Dusseldorf Tower, D-EAZF"** (Q73). No "over", "from", "is calling".
* Radio is simplex: listen before transmitting; two at once = "two stations calling together".

## 6. READBACK — WHAT TO SAY BACK  (Q44–Q48, Q74–Q76)
**HOW TO USE:** *"If misheard could hurt you, read it back."* **Read back:** runway in use, clearances (take-off, landing, line-up, crossing, airspace), altitude/level, heading, speed, altimeter setting, SSR code, frequency, taxi/hold instructions — end with your call sign.
**NO readback:** **wind, traffic information** (Q46, Q47). Altitude, SSR code, runway, heading, taxi, altimeter DO need readback.

Worked examples:
* "DZF after lift-off climb straight ahead until 2500 ft before turning right heading 220, **wind 090/5**, **runway 12**, cleared for take-off" → **"DZF after lift-off climb straight ahead 2500 feet, then turn right heading 220, runway 12, cleared for take-off"** (Q44: **omit wind**, no extra "wilco").
* "Call Hamburg Tower on 121.275" → **"121.275"** (Q74).
* "Squawk 4321, call Bremen Radar on 131.325" → **"Squawk 4321, 131.325"** (Q76).
* "You are now entering airspace Delta" → **"Roger"** (Q45).
* "Next report PAH" → **"Wilco"** (Q75).

**Leaving a control frequency** (except at final parking position) **must be approved** (Q48).

## 7. MESSAGE PRIORITY  (Q12, Q13, Q68)
1. **Distress** (MAYDAY)  2. **Urgency** (PAN PAN)  3. **Direction-finding communications** (e.g. "Request QDM")  4. **Flight safety messages** (ATC: clearances, "turn left") — *"message used for air traffic control"* (Q12)  5. **Meteorological** (wind, QNH)  6. **Flight regularity**.
Mnemonic: **D-U-D-F-M-R** = "**D**ogs **U**sually **D**ig **F**or **M**any **R**abbits".
* Q13: Request QDM (DF) > turn left (flight safety) > wind/QNH (met).
* Q68: higher than flight safety = **direction finding**.

| Type | Definition (bank wording) |
|---|---|
| **Distress** | aircraft & passengers face a **grave and imminent threat**, require **immediate assistance** (Q58, Q81) |
| **Urgency** | **safety of an aircraft, watercraft or other vehicle or person in sight** (Q61, Q80) |
| **Flight safety** | ATC-type messages (Q12) |
| **Regularity** | **operation or maintenance of facilities essential for safety/regularity of flight operation** (Q69) |
Traps: "urgent spare parts", "apron personnel" are wrong.

## 8. EMERGENCY CALLS  (Q58–Q63)
| | **MAYDAY** (distress) | **PAN PAN** (urgency) |
|---|---|---|
| Repeat | **MAYDAY ×3** | **PAN PAN ×3** (Q62) |
| Meaning | grave & imminent danger | urgent safety matter, no immediate danger |
| Frequency | **CURRENT frequency** for the initial call (Q59) — not radar/FIS/emergency freq | current frequency |
| Squawk | **7700** (Q60) | 7700 as appropriate |

**Order:** MAYDAY/PAN PAN ×3 → station addressed → call sign → aircraft type → **nature of problem** → **pilot's intentions** → **position, altitude, heading** → other info (persons on board, endurance).
**Urgency content (Q63):** nature of problem or observation · important info for support · pilot's intentions · position, heading, altitude. (Wrong options add departure/destination aerodrome/routing.)

Example: *"MAYDAY MAYDAY MAYDAY, Delft Tower, OO-ABC, Cessna 172, engine failure, making forced landing, 5 NM south of Delft, altitude 2000 ft, heading 360, 2 persons on board."*

## 9. TRANSPONDER CODES  (Q56, Q57, Q60)
| Code | Meaning |
|---|---|
| **7000** | VFR conspicuity |
| **7500** | Unlawful interference / hijack |
| **7600** | **Radio failure** (Q56, Q57) |
| **7700** | **Emergency** (Q60) |
Order 75-76-77 = **H**ijack – **R**adio – **E**mergency. Trap: flight into cloud ≠ 7600; hijacking = 7500.

## 10. RADIO FAILURE & BLIND TRANSMISSION  (Q30–Q33, Q54, Q55, Q78, Q79)
Steps: check frequency, volume, headset/plug, station; try another frequency; **squawk 7600**; **transmit blind**.

**Class D (VFR):** continue **according to the last clearance, complying with VFR, or leave the airspace by the SHORTEST route** (Q54). **Enter class D with radio failure only if approval was granted BEFOREHAND** (Q55, Q79) — not because it's departure/destination aerodrome or other aircraft in circuit.
Traps: "above 5000 ft", "standard route".

**Blind transmission**
* When: **no contact possible but evidence that the ground unit receives you** (Q33).
* Phrase: **"TRANSMITTING BLIND"** (Q32); receiver failure: "…BLIND DUE TO RECEIVER FAILURE".
* Frequency: **the current frequency** (Q30).
* Repeats: CAP 413 = **twice** → Q31 "Twice". ⚠ **Q78 (same topic) lists "One time" as correct.** If "Twice" is offered pick Twice; if options are Two/Three/Four/**One time** pick One time.

## 11. Q-CODES & ALTIMETRY  (Q7–Q11)
| Code | Meaning |
|---|---|
| **QFE** | altimeter shows height above reference airfield → **0 on the ground** (Q7, Q8) |
| QNH | altitude above mean sea level |
| QNE | 1013.25 hPa datum (flight levels) |
| **QDM** | **magnetic** bearing **TO** station |
| **QDR** | **magnetic** bearing **FROM** station |
| **QUJ** | **true** bearing **TO** station (Q10) |
| **QTE** | **true** bearing **FROM** station (Q9, Q11) |
Mnemonic: D = magnetic (QDM/QDR); U-J-T-E = true. QDM→"M"= *to Me*(to station); QTE: "E" = *exit/from*. Don't swap QTE/QUJ: both true, QTE = from, QUJ = to.

## 13. WEATHER / BROADCASTS  (Q49–Q53, Q77)
* METAR cloud oktas: **FEW = 1–2** · **SCT = 3–4** · **BKN = 5–7** · **OVC = 8** (Q49, Q50).
* **VOLMET** = meteorological information broadcast for en-route use (Q51, Q52). Not AIRMET/GAMET/METAR (those are reports/forecasts).
* **ATIS** valid **30 minutes** (Q53) (new information letter on change); may be broadcast on a **VOR** (Q77), not GPS/DME/NDB.

## 14. RADIO WAVES, VHF & RANGE  (Q64–Q66, Q82)
* Speed of electromagnetic waves = **300,000 km/s** (Q64) (not m/s).
* f = c / λ (λ 100 m → 3 MHz). **VHF = 30–300 MHz** (λ 10–1 m). Voice band **118.000–136.975 MHz = VHF** (Q66); unit **MHz** (118.75 MHz, Q65), not kHz.
* Aviation voice uses **AM**, simplex.
* VHF = **line of sight** → range depends on **altitude** (Q82); shoreline effect, twilight error and ionosphere height are HF/NDB effects.
* **Range (NM) ≈ 1.23 × √(height ft AGL) + 10 %**
  * 10,000 ft: 123 + 12.3 = **135.3 NM**; 6,400 ft: 98.4 + 9.8 = **108.2 NM**.

## 16. EXAM TRAPS
* Roger ≠ yes ≠ permission ≠ wilco.
* No readback of wind or traffic info.
* Time = UTC, digit by digit; altitude uses hundred/tousand, heading doesn't.
* Distress = grave+imminent; urgency = safety/in sight.
* Initial distress call on the **current** frequency.
* Radio failure: 7600; class D entry only with prior approval; leave by shortest route.
* QTE (true from) vs QUJ (true to); QFE = zero on ground.
* Blind transmission count: Twice (Q31) vs One time (Q78) — read the options.
