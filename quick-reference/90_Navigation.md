# Navigation — Quick Reference

*Label every direction with its reference: true, magnetic, compass, course, or heading.*

## Earth, distance, time

| Rule | Recall |
|---|---|
| 1 minute latitude | Approximately 1 NM |
| 1 degree latitude | 60 NM |
| Great circle | Shortest route on a sphere |
| Rhumb line | Constant direction; straight on Mercator chart |
| ETA leg time | \(t(\text{min})=60\,d(\text{NM})/GS(\text{kt})\) |

## Direction chain

\[
\text{Heading}=\text{Course}+\text{WCA}
\qquad
\text{True}=\text{Magnetic}+\text{Variation}
\qquad
\text{Magnetic}=\text{Compass}+\text{Deviation}
\]

Treat variation and deviation as signed values and work in the direction required. Check the chart's variation and aircraft compass deviation card.

- Wind is named for where it comes **from**; headwind lowers GS, tailwind raises it.
- Crosswind correction points into the wind; \( \text{heading}=\text{course}+\text{WCA} \).
- 1-in-60: track error \(\approx60\times\) cross-track error ÷ distance flown. To intercept the destination, account for both track error and closing angle.

## Bearings, compass, TAS

| Term | Quick meaning |
|---|---|
| QDM | Magnetic bearing to station |
| QDR | Magnetic bearing from station |
| QTE | True bearing from station |
| RBI/NDB | QDM ≈ magnetic heading + relative bearing (wrap 000°–359°) |

- TAS rule of thumb: IAS increases about 2% per 1,000 ft; use proper corrections/data when available.
- UNOS (Northern Hemisphere): undershoot north, overshoot south when rolling out on a magnetic compass.
- ANDS (Northern Hemisphere): accelerate → apparent turn north; decelerate → apparent turn south, on east/west headings.
- Use visual checkpoints, current charts/NOTAMs, and radio/GNSS aids as cross-checks, not substitutes for situational awareness.
