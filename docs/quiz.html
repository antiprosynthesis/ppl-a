⚙️ Save reports to the GitHub repo (optional)

A web page cannot write to your repo by itself. Either download the report and commit it, or paste a fine-grained personal access token (only this repository, permission Contents: read & write) and the quiz will commit the report into results/ for you. Or run python3 quiz/serve.py locally: then it uses your own git login and needs no token. The token is stored only in this browser (localStorage).
